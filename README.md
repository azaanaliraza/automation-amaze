# automation-amaze

Amaze Matrix — premium AI automation agency website for local businesses (AI chatbots, WhatsApp automation, appointment & lead systems).

## Stack

- Astro 5 (static-first) + Bun + TypeScript
- Tailwind CSS v4, React islands, Lenis, GSAP, Motion, Lucide icons

## Develop

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
bun run preview
```
